## **Виклик**

Головним завданням було розробити та стабілізувати платформу **Liva Clinic** — комплексну екосистему для цифрової медицини, що об'єднує клініки, лікарів та пацієнтів. Проєкт складався з трьох окремих застосунків: пацієнтського веб- та мобільного порталу для пошуку лікарів та запису на прийом, робочого кабінету лікаря для ведення розкладу та онлайн-консультацій, а також адміністративної панелі для менеджменту клініки. Основними технічними викликами були побудова безпомилкового календаря з підтримкою різних часових поясів, усунення перетинів слотів для регулярної доступності лікарів, інтеграція зашифрованих відеоконсультацій через Agora та обробка платежів через Stripe Connect.

---

## **Рішення**

Працюючи над клієнтською та серверною частинами проєкту, я реалізував оптимізацію та розширення функціоналу:

У межах кросплатформної розробки на Flutter я стабілізував та вдосконалив адаптивні інтерфейси для Web та Mobile з використанням Clean Architecture та BLoC, реалізувавши плавний інтерактивний календар вибору слотів, пошук з фільтрами та особистий кабінет.

На бекенді я оптимізував сервіси на базі Node.js / Express з PostgreSQL та Sequelize, переписавши алгоритми перевірки доступності та періодичних слотів із коректною конвертацією часових поясів.

Для телемедицини інтегрував Agora RTC для проведення відео- та аудіоконсультацій у реальному часі, Google Maps API для верифікації локацій кабінетів, SendGrid для поштових сповіщень та Twilio для SMS-нагадувань.

Також налаштував інтеграцію зі Stripe та Stripe Connect для безпечної оплати консультацій та автоматичного розподілу коштів між клінікою та лікарями, а також сервіси AWS (S3 для збереження медіафайлів та CloudWatch для моніторингу логів).

---

## **Результат**

Платформа отримала високу швидкість роботи, надійність та зручний інтерфейс на мобільних пристроях і у браузері. Лікарі отримали зручний інструмент для керування робочим часом та віртуальними прийомами, а пацієнти — можливість швидко знаходити потрібних спеціалістів, бронювати час без ризику подвійних записів і проходити відеоконсультації. Адміністративна панель суттєво зменшила рутинне навантаження на персонал клініки.
